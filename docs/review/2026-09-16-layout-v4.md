## What the latest evidence actually says

The contact control's first evaluations are labelled `init`, before optimizer updates.
They compare best-of-four proposals using selection reads and independent assessment.
They are continuation diagnostics, not an empty-start construction comparison.

| Initial policy comparison | Pegasus 6 | Zephyr 4 |
|---|---:|---:|
| Policy utility minus restart utility | -0.1037 [-0.1811, -0.0262] | -0.0634 [-0.1110, -0.0160] |
| Source | `results/contact/pegasus6_control.log` | `results/contact/zephyr4_control.log` |

These results withdraw the interpretation of growth-versus-one-start as a learned gain.
They do not prove that every trained contact policy is inferior: these control logs have
only 3 and 12 subsequent training iterations, with no later assessment. Hybrid v3's board
also reports no demonstrated gain; its cited new raw logs are not in this checkout.

One residual control defect is fixed here: a failed fresh router proposal was replaced
with the supplied start. Failed attempts now remain failed, without a free replacement;
read use, coverage and per-arm time are logged. Historical numbers are not recomputed.
Contact's read cap is not a wall-time match and cannot support an end-to-end runtime claim.

## Reproducible barriers in the current root policy

1. On a path of seven host nodes, once a neighboring logical variable is placed at 3,
   legacy support offers only 2 and 4. Root 6 has probability zero although a valid
   completion can connect it using a chain through 3, 4 and 5. This proves excluded
   support, not that every nonlocal choice improves quality.
2. On the same path25 task, candidate root0 has identical old features when an occupied
   neighbor is at5 or20. Its residual free component has size5 or20. The feature encoder
   cannot expose this difference to any downstream optimizer.
3. Swapping coupling strengths10 and1 between two placed logical neighbors preserves
   the old degree/contact/magnitude summaries. The strong-coupling direction is hidden.

The old features already include per-variable coefficient magnitudes. The problem is
missing association and residual connectivity, not an absence of all physical inputs.
These counterexamples motivate fixes; they do not establish the cause of every failed run.

## Explicit deployment and learning contract

Input is the logical graph and Ising coefficients, hardware graph, and declared budgets.
Every rollout starts with empty chains. The logical-variable ordering is unchanged.
The actor chooses a free physical root for each logical variable. A root cannot overlap
another root or exceed the qubit cap. A root action is locally legal, not guaranteed
extendable. Minorminer completes or rejects the layout within the remaining deadline.
The final validator, budget and deadline decide whether a complete output is admissible.
No witness, supplied embedding, teacher logits or ground-truth quality enters inference.

This remains a **hybrid root-placement policy plus router**, not a learned complete
minor-embedding generator. The router may reroute initial chains. This patch does not
implement the full relaxed-overlap PPO architecture described in the earlier manuscript.

### Support and representation

`--root-support all_free` exposes every currently free host node. `legacy` retains the
old touching48/spread24 restriction for an ablation. All-free support has a real inference
cost: approximately n times m candidate rows, and larger autograd storage during training.
Feature extraction and proposal time count against the same deployment deadline. A support
gain that disappears after this cost is counted is not a runtime gain.

`--features capacity` uses schema `layout-v2`, 65 dimensions. The first35 old channels
remain unchanged. Thirty appended channels expose:

- Residual component fraction, free degree, articulation, minimum/maximum onward branch
  capacity, fragmentation and local dead ends.
- Maximum available branch capacity for positive/negative changes in each native topology
  coordinate. These are topology-index directions, not Euclidean compass directions.
- Edge-specific coupling-weighted distance, contact and unreachable fraction for placed
  logical neighbors; signed field/coupling summaries and strongest-coupling distance.
- Actual occupancy, unplaced-variable fraction, unmet-edge fraction and remaining budget.

Low-link analysis caches components and onward capacities once per complete membership
state. Distances traverse free nodes and touch only the target chain at the endpoint.
Branch capacities on a cycle can overlap; they are not summed. Signed channels are not
gauge invariant. These features are neither a sufficient Markov representation nor an
annealing-quality certificate. Future graph encoders must be compared on the same support.

### Contextual actor and critic

For candidate features x_q, the shared encoder produces h_q. Pooling gives

    c = concat(mean_q h_q, max_q h_q, log(1 + |support|)).
    logits_q = actor(concat(h_q, c)); V = critic(c).

The actor is equivariant to a permutation of candidate rows; the value is invariant and
computed before choosing an action. This is a candidate-set network inspired by
[Deep Sets](https://arxiv.org/abs/1703.06114), not a GNN or a novel invariance theorem.
`--actor local` retains the independent MLP, including with the new inputs/support.
Checkpoint metadata binds model type, feature schema, width and input dimension;
incompatible schemas are rejected instead of silently reusing weights.

### Loss and teacher

The terminal reward and registered evaluator remain unchanged. Quality is a bounded
monotone transformation of measured residual improvement over a training-only reference;
invalid completion gets the existing bounded partial-overlap score. No chain-length or
qubit-minimization penalty is added. A constant valid reward cannot teach quality.

Each fresh trajectory is used once. With gamma=1, all placement states receive the
terminal return R as a Monte Carlo target. In `--baseline value`,

    A_t = R - stop_gradient(V(s_t))
    L_actor = -sum_t A_t log pi(a_t | s_t)
    L_value = mean_t Huber(V(s_t), R)
    L = mean_episodes[L_actor + c_v L_value - c_H mean_t H(pi_t)/log(|A_t|)].

One-action entropy is defined as0. Advantages are detached. There is no discount,
bootstrapping, replay, surrogate clipping or PPO multi-epoch update. The existing
leave-one-out baseline is available independently of architecture. The actor loss sums
decisions; averaging it by trajectory length would change the task weighting.
The critic is a variance-reduction hypothesis, not an oracle continuation-Q estimator.

Optional `--warmstart-epochs` uses only training-lineage witnesses after the split.
A teacher prefix places one random root in each earlier variable's disjoint witness
chain. The target set S contains all offered roots in the current witness chain:

    L_teacher = -log sum_{q in S} pi(q | prefix).

No absent teacher candidate is injected. Missing teacher support is logged. Witnesses
must be valid and fit the declared budget. This teaches **compatible feasibility roots**,
not downstream quality and not a distribution of action advantages. It avoids choosing
an arbitrary canonical qubit. Prefix teaching still has distribution shift; the following
on-policy stage must demonstrate transfer. Validation never reads these teachers.

Training logs now include reward/advantage standard deviation, normalized entropy, mean
support size, gradient norm and value explained variance. Zero return variance with LOO
explains a zero actor update; a critic loss decreasing by itself is not policy improvement.
Validation remains separate from training RNG; its role is checkpoint selection, not final test.

## Ordered ablations and remote commands

The launcher runs one arm, never overwrites existing logs, and retains a common evaluator:

| Arm | Support | Features | Actor | Baseline | Teacher |
|---|---|---|---|---|---|
| legacy | legacy | old35 | local | LOO | none |
| support | all free | old35 | local | LOO | none |
| capacity | all free | new65 | local | LOO | none |
| context | all free | new65 | contextual | LOO | none |
| critic | all free | new65 | contextual | value | none |
| warm | all free | new65 | contextual | value | 5 epochs |

All arms initially use entropy coefficient0. Test exploration separately with
`--entropy-coef 0.01`, keeping the chosen arm fixed. Do not attribute a combined-arm
improvement to one component. Each trained run also needs its untrained control.

On the experiment host, with the project's environment activated:

```bash
bash scripts/apollo/run_hybrid_v4_arm.sh "$CORPUS" runs/hybrid_v4/support_s0 support 0
bash scripts/apollo/run_hybrid_v4_arm.sh "$CORPUS" runs/hybrid_v4/capacity_s0 capacity 0
bash scripts/apollo/run_hybrid_v4_arm.sh "$CORPUS" runs/hybrid_v4/warm_s0 warm 0
```

Start with a small learnability setting. Proceed to the other arms and at least three
independent training seeds only if there is nonzero reward variation and improving
completion. Compare against **restarted minorminer plus measured selection** under the
same full deployment wall time, reads, decoder, strength rule and qubit budget. Use
matched task/assessment seeds. Do not interpret best-checkpoint validation as an unopened
test. Report feasibility on all instances, measurement coverage, paired quality on common
successes, and the exact missing-output treatment. A conditional quality gain with a large
coverage loss is not a general embedder win.

Qubit caps are externally supplied conditioning/constraints, not a teacher-derived test
budget. Repeat across declared budgets to estimate a resource-quality frontier. Root-only
training does not yet learn when to extend a completed chain or jointly tune strength;
those remain separate hypotheses requiring ablation.

## Verification and remaining evidence

`results/audit/layout_v4_unit.log` records deterministic unit/integration checks and a
tiny synthetic overfit gate. The latter targets the nearer strongly coupled neighbor;
it is not an annealing measurement or a hardware result. The old features alias opposite
targets; the new features let the small contextual model separate them.
The targeted suites pass 112 tests. In the seeded toy check, mean probability on the
synthetic target rises from 0.499765 to 1.000000 (rounded); this is an overfit sanity check.

The full unit command was attempted and collection is blocked by the absent built
`lac_minorminer._core` extension. Targeted suites exercise the changed feature, sampler,
loss, checkpoint, training CLI and restart-control paths. No remote benchmark, real-QPU
evaluation or A* acceptance claim follows from these checks.
The experiment host alias `apollo` cannot be resolved from this workspace, so the remote
recipes have not been launched here. Current fast-sampler RNG uses NumPy; legacy mode
preserves its distribution/support, not bitwise trajectories from old Torch sampling.

Paper gate: a learned gain that survives strong measured-selection baselines, held-out
lineages and larger hosts on both Pegasus and Zephyr, training-seed uncertainty, all
failure accounting, and the above ablations. Architectural correctness is necessary;
competitive results and a distinct scientific contribution are still unproven.
