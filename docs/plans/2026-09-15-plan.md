# Implementation plan: RL embedder relaunch

Follows `docs/specs/2026-09-15-rl-embedder-relaunch.md`. Tasks are small, each with acceptance
and a verification step. Checkpoints decide whether the next phase runs.

## Architecture decisions
- ADR-001: one compiled program for labels and observations.
- ADR-002: the registered schedule is the objective.
- ADR-003: constructive formulation, gated.
